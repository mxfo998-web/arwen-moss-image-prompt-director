# 原创结构示例

这些是原创建模/排版示例，只做过格式、坐标、文字保留和编译校验，没有调用 MOSS 生成图片，不表示已经验证画质或一致性。

| 示例 | 画布 | 用途 |
| --- | --- | --- |
| coffee-poster | 1024×1536 | 中文海报 Layout，含三个文字项 |
| cinematic-still | 1536×864 | 双人电影静帧 Layout，无文字项 |
| storyboard-two-panel | 1536×1024 | 一张左右两格故事板，整画布坐标，无文字项 |
| cinematic-caption | 按用途选择，建议 1536×864 | 自然语言电影静帧，不需要 Layout |

每个 .draft.json 是可编辑草稿；.prompt.txt 为官方编译器输出。Layout 文件是一物理行 JSON，Caption 文件是纯正文。

海报文案是虚构示例，不包含真实商品功效、价格或活动信息。coffee-poster.copy.json 用于逐字符核对文字；不需要画出坐标框。

改画布或几何后重新编译；改文字时核对原文与排版，不把结构校验标成实际图像验证。

## 语言选择示例

这些示例文件保留中文版，使用时按 [语言选择](../SKILL.md#语言选择) 决定是否另写英文对照：

| 请求 | 应交付 |
| --- | --- |
| 未指定语言：写一只陶瓷杯的简洁静物提示词 | 完整中文提示词 |
| 未指定语言：三名人物分别持不同道具，含前后遮挡、明确站位与多块文案 | 中文、英文两个完整版本，正文外说明二选一输入 |
| 上述复杂画面，但明确“只要中文” | 只交付中文版 |
| 简洁静物，明确“中英双版” | 中英各一份，不增加两版之间的画面差异 |
| 英文描述的中文海报，标题指定“夜航” | 描述用英文，可见标题仍为“夜航”，标点和换行照原文保留 |

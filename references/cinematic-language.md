# 影视视觉语言

适用于电影静帧、电影海报、剧情插画和故事板。下列是摄影与视觉叙事知识，不是 MOSS 专有控制开关；实际模型执行程度须出图验证。

## 从叙事目的开始

先确认这一画面主要表达人物、关系、空间、信息、动作还是世界尺度，再选择景别、位置、光色和质感。可以混合类型，但保持一个主视觉逻辑，不把所有电影术语同时写进一张图。

每个方法记录：叙事目的 → 可见效果 → 适用场景 → 具体写法 → 冲突检查。类型和情绪只提供方向，不形成“某种颜色永远代表某种情绪”的规则。

## 电影色调

至少区分下列变量，按需选择：

| 变量 | 可观察的描述 |
| --- | --- |
| 主色、辅色、点缀色 | 深海军蓝环境，少量琥珀灯光，红色围巾作为视觉焦点 |
| 饱和度 | 环境颜色克制，主体保留适量色彩；或明确的高饱和设计 |
| 反差与黑位 | 强烈明暗分区但暗部有纹理；或柔和低反差 |
| 高光过渡 | 窗口明亮但边缘柔和，皮肤高光不过度尖锐 |
| 肤色与局部色偏 | 冷环境里保持自然肤色；受霓虹照射的一侧保留局部染色 |
| 色彩分离 | 前景暖、背景冷，或用相近色形成统一空间 |
| 曝光与明度分布 | 亮部集中在人物面部，背景低亮度并保持空间线索 |

“低饱和”与“低反差”不同；“暗调”与“细节全黑”不同。光源颜色、白平衡观感、场景物体颜色与后期色调共同形成结果，不能只写一个色温数字保证暖冷。

写法示例：环境以低饱和冷青灰为主，脸部保留自然偏暖肤色，亮部集中在门口，阴影保留层次，窗光高光过渡柔和。

## 灯光与来源

- 说明可见或合理的来源：窗、太阳、台灯、顶灯、屏幕、路灯、火焰等。幻想光源也要说明照射对象和环境后果。
- 区分侧光、侧逆光、顶光、正面柔光、轮廓光；明确左右是以画面还是人物为参照。
- 软硬由阴影边缘和高光形态描述；例如窄窗硬光、漫射天光、柔和大面积窗光。
- 主光/填充决定脸部和空间明暗；负补光表现为一侧暗部更深，不是添加黑色物体。
- 不自动给所有人像套伦勃朗光、橙青配色、烟雾、光束或镜头炫光。
- 体积光需要介质和合理光路；反射、阴影、轮廓与主光位置一致。

## 构图

| 方法 | 使用时关注 |
| --- | --- |
| 居中、对称 | 秩序、仪式、僵持或明确图形关系，避免无意对称 |
| 偏置、三分 | 人物与环境的权重，不能机械地每图三分 |
| 负空间 | 留给视线、未知信息、距离或文字，明确哪一侧空 |
| 框中框、前景遮挡 | 观察位置、隔阂、偷窥或空间深度，保护主体可读 |
| 引导线、透视汇聚 | 目光路径和目的地；线条不要无意指向次要对象 |
| 前中后景 | 尺度、深度与环境关系，避免每层同样清楚同样抢眼 |
| 人物距离与层次 | 亲近、分离、对峙；用具体站位、朝向和遮挡体现 |
| 头顶空间与视线空间 | 与动作/视线一致，刻意压迫构图须有目的 |

电影海报允许图形拼贴和多尺度组织；连续剧情静帧优先保持统一空间逻辑。用户没要求时，不自动加黑边、字幕或电影标题。

## 景别

- 大远景/大全景：环境、世界规则、人物与空间尺度。
- 全景/中远景：完整动作、人物站位、身体关系和路径。
- 中景/双人景：互动、手部动作和关系。
- 中近景/近景：表情、视线、认知和情绪。
- 特写/插入：关键细节、线索、触点；不要因“电影感”让所有镜头都成为特写。

景别与取景边界协调：需要完整手脚的动作不可同时切成脸部特写。若主体在框里很小，微表情不能作为主要证据。

## 机位、角度与人物朝向分开

1. 摄影机高度：地面、膝部、腰胸、眼平、高位。
2. 俯仰：水平、轻微仰拍、俯拍、垂直顶视。
3. 方位：正面、侧面、三分之四、背面、过肩、角色主观。
4. 横滚：水平或有意倾斜。荷兰角用于特定失衡感，不作为通用装饰。
5. 人物自身朝向与视线：面向谁、看向何处、身体与头部是否一致。

低机位不自动等同仰拍：相机可在低处水平看向远景。人物转身和摄影机绕行也不是同一件事。单张静帧选择一个一致的视点，不混写互斥机位。

## 焦段、距离与景深

- 透视关系由摄影机位置决定；焦段、距离、画幅和裁切共同影响构图。避免把“长焦”写成不依赖机位的空间压缩开关。
- 近机位配合较广视角可强调前后比例与身临其境；远机位配合长焦可在相近主体占幅下呈现压缩感。
- 数字焦距只是辅助意图。需要时注明全画幅等效视角，并描述最终空间效果；不要靠堆相机/镜头型号代替画面。
- 景深说明焦点落在谁、前景或背景如何虚化；不同时要求全景深和所有非主体强烈失焦。
- 多人重要信息分处前后景时，选择足够景深或明确焦点策略。

## 质感

颗粒、轻微高光晕染、柔化、边缘锐度、镜头反射和材质纹理各自控制。电影画面可以干净锐利，也可以柔和粗粝，依据题材选择。

胶片感不等于全图模糊、灰雾、划痕或永远暖色。皮肤和衣物要符合光照；眼睛、头发和背景的精修程度可以有主次。

## 类型选择示例

- 剧情/爱情：人物距离、等待与视线关系；用环境和关系道具支持表演，颜色可以冷也可以暖。
- 悬疑/犯罪：控制观众看见的信息，利用门框、反射、遮挡和负空间；保证线索可读。
- 科幻：用人物/建筑建立尺度，技术有用途，光源与材质有依据；不要把霓虹和全息屏作为所有科幻的默认答案。
- 武侠/动作：先建立完整身体、兵器、接触和地理；关键一帧有重心、路径和结果，避免特效遮住证据。
- 历史/年代：服装、建筑、灯具、文字与物件服从时代地域；用座次、门槛和高度关系表现权力。
- 喜剧：让人物、道具与误差关系同框可读；夸张程度服从媒介。
- 动漫：先锁主媒介、线条/笔触、形体比例、用色和光照；不能同时默认写实毛孔、摄影闪光和二维平涂。

## 连续分镜

- 多张独立图与一张多格图先区分。多格统一全板媒介和光色；每格可有不同机位与景别。
- 记录身份、服装、持物、损伤、环境状态、时间、主光方向、屏幕方向、视线和轴线。
- 一个镜头冻结一个主要时刻。预备、接触、反应与结果分开，不在一格叠加多个时间状态。
- 景别改变应增加信息或改变关系；必要时用宽景重新建立空间。
- 过轴或改变方向应有明确意图与空间依据，不把轴线规则当作禁止所有变化。
- 为后续视频保留动作和视线空间；摄影机运动写在镜头说明里，静帧正文描述某一时刻的视点与状态。

## 写入 MOSS

单画面的全局光色、景别、机位和质感放 summary.caption；人物局部表现放对应 items[].caption；bbox 只负责位置范围。

多格镜头各自的摄影描述放在该格的元素 caption，全局 summary 不指定互斥的单一摄影机。不要添加 color_grading、camera、lens、shots 等字段。

检查：叙事重点是否可见；是否有两种互斥角度；景别是否允许看清指定细节；光源、反射、阴影是否一致；色调是否污染文字或品牌色；前后格是否保持连续。
